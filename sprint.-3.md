# Sprint 3 · Scripts, Procesos, Docker y Kubernetes

[⬅ Volver a la portada](README.md)

## 1. Desarrollo y Despliegue
Implementación de scripts de consola y gráfico (`.desktop`), simulación de procesos (`zombi.py`), creación de imagen en **Docker** y despliegue en **Minikube/Kubernetes**[cite: 2].

## 2. Comandos utilizados
| Comando | Para qué sirve |
| :--- | :--- |
| `ps aux` | Listar los procesos activos y estados en el sistema |
| `docker build -t usuario/imagen .` | Construir la imagen de contenedor |
| `docker push usuario/imagen` | Publicar la imagen en Docker Hub |
| `kubectl get pods` | Verificar los pods desplegados en Kubernetes |
